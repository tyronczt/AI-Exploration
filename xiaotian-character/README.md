# 小天 Agent 人物形象 Skill

为技术文章和视频讲解制作统一的人物素材：立绘、表情、讲解姿态和参考图编辑。

版本：**v0.1.1**。角色为猫耳拟人程序员，采用温暖手绘基调，支持标准手绘版与信息图简化版。

## 快速使用

下载完整的 `xiaotian-character/` 文件夹，保留内部目录结构。不要只下载 `SKILL.md`，角色规范和图片也是技能的一部分。

在支持加载本地指令文件的 Agent 中，提供下载后的真实路径，例如：

```text
读取 ./xiaotian-character/SKILL.md，使用包内角色规范和参考图，
生成一张小天向右指向的半身讲解人物，浅色背景，不添加文字。
```

也可以把整个文件夹放入所用 Agent 支持的技能目录，按该工具的方式加载。技能被识别后，可使用：

```text
使用 $xiaotian-character，为小天设计一个托腮思考姿态，先输出提示词，不生成图片。
```

无需原作者的聊天记录、本机路径或额外参考仓库。实际生成、编辑图片需要宿主提供图像工具；只有文本能力时会输出提示词，不会生成图片文件。此技能不绑定特定模型或 API 服务。

## 常见用法

| 需求 | 示例请求 |
|---|---|
| 先审核提示词 | 为小天设计正面全身立绘，先给提示词，不出图 |
| 文章人物素材 | 生成信息图简化版小天，站在画面左侧向右讲解，给右侧留白 |
| 视频人物素材 | 生成标准手绘版小天的正面半身讲解关键帧，手势自然 |
| 修改现有图片 | 保持脸型、服装和姿态，仅修正工具腕带到角色自身左侧 |
| 检查一致性 | 对比这张图与包内参考，指出人物身份、动作和裁切问题，先不修改 |

普通生成请求直接执行，不要求先建立母版。需要长期固定多个视角时，再按需求建立用户专用母版。

## 默认视觉

深棕短发、深色猫耳、圆形黑框眼镜、深蓝卫衣、米色咖啡杯齿轮徽记与左侧工具腕带。具体默认值以 [角色规范](references/character.md) 为准。

![温暖手绘风格与人物示例](assets/character-style-reference.png)

这张图用于展示画风、人物可见外观及辅助讲解构图。生成单人物素材时不复制其中的文字、卡片或流程箭头；它不是完整的多视角设定表。

## 文件与阅读顺序

```text
xiaotian-character/
├── README.md                           # 面向使用者：安装与示例
├── SKILL.md                            # 面向 Agent：触发与执行流程
├── agents/
│   └── openai.yaml                     # 支持该格式的宿主界面配置
├── references/
│   ├── character.md                    # 唯一角色规范与参考用途
│   └── prompts-and-qa.md               # 提示词、动作与验收
└── assets/
    └── character-style-reference.png   # 默认图像参考
```

使用者从本页开始；Agent 从 [SKILL.md](SKILL.md) 开始，再按需读取引用文件。全部本地引用位于同一技能包内，移动目录不会改变它们的相对关系。

## 输出与范围

生成任务输出人物图片及简短记录，包括使用的参考、实际提示词和验收结果，保存到当前工作区，不覆盖技能包。提示词任务仅交付文字方案。

当前技能负责人物形象与素材，不包含文章全文配图编排、视频配音、口型驱动或成片剪辑。静态图检查不能证明视频连续性；角色一致性仍需查看生成结果。

发布文件仅保留上述技能包内容。调研、旧方案、候选样图和任务输出不作为技能依赖，也不应放入发布包。
