# 小天动画视频

生成实际可播放的动画视频。脚本、分镜、关键帧、运动提示词是中间材料，不能替代成片。只有静态图片的平移、缩放或切换不算完成人物动画。

## 依赖与执行边界

读取包内 [角色规范](../references/character.md)、[人物制作流程](../references/character-workflow.md) 和 [默认参考图片](../assets/character-style-reference.png)。按本能力要求组织内容，角色身份与品牌基调保持统一。所有引用均在同一技能包内，无需另装人物技能。

先确认当前环境实际具备的视频生成或动画渲染能力，不预设已安装某个插件、模型、CLI 或 API。图像工具只负责关键帧，不冒充视频工具。真正的角色关节/表情动画渲染也可使用，但不能以整张图片移动替代角色运动。

明确要求“先分析/分镜/提示词”时不生成视频。明确要求动画且能力齐备时执行到成片。涉及额外付费或将素材上传外部服务时，先说明具体服务、素材范围与费用估计并取得相应授权；本次已有明确授权的范围不重复询问。

没有视频能力时交付可用分镜与运动提示词，并明确“动画未生成”，不返回伪造视频路径或以静态预览宣称完成。

## 从内容到动画

1. 读取内容，确定核心观点、受众、时长、比例、声音与用途。普通短试片未指定时可采用 16:9、约 6–8 秒、无旁白的单动作镜头，说明假设；长篇讲解时长不清会影响成本与覆盖时，先确认范围，同时整理脚本。
2. 将知识组织为镜头。A-roll 是小天的主体讲解镜头；B-roll 是机制演示、操作或概念画面。每个镜头一个主要动作，标清它解释什么，不为炫技添加无关动作。
3. 先列准事实、标签与关系，再确定视觉。复杂文字和技术图形宜作为稳定叠加层，不要求视频模型在运动中不断重画小字。不得把动画生成的日志或画面冒充真实运行证据。
4. 选择小天参考并生成必要关键帧，核对身份、朝向、道具及留白。只生成当前镜头实际需要的视角；关键帧无明显身份错误后再用于运动生成。
5. 用关键帧或实际人物素材与运动提示词驱动可用视频工具。多镜头或高成本任务先完成一个短试片，检查身份和真实动作后再扩展；用户只要单短片时不额外增造测试片。
6. 必要时按脚本剪辑、叠加标签或字幕、处理声音并导出实际视频，默认 MP4，采用环境支持的常用编码。旁白仅在任务需要时制作；无音轨成片明确标注，不把缺旁白的版本当作已完成口播。
7. 播放最终文件并检查下述项目，交付视频与必要的简短说明。

## 讲解主线与镜头选择

先把文章改成能听懂的讲解稿：问题或具体情境 → 核心解释 → 演示或证据 → 结论与边界。按需要取舍，不逐段朗读文章，也不把文章整张总览图当作所有镜头的底板。每个镜头只承担一个主要认知任务；旁白可跨切镜连续，A-roll 与 B-roll 不必机械交替或按固定比例分配。

| 镜头 | 何时使用 | 小天与信息的关系 |
|---|---|---|
| A-roll 人物讲解 | 提出问题、解释判断、转折、总结 | 小天为主体，半身或中景，目光与手势有明确对象；背景简洁，可配一个关键词 |
| B-roll 知识卡片 | 定义、少量要点、对比结论 | 按讲解顺序突出当前要点，不铺满整页文字；小天可在侧边提示，也可不出现 |
| B-roll 流程演示 | 调用顺序、数据去向、状态变化 | 分步出现节点或高亮路径，箭头语义准确；人物不代替运行时、模型或工具节点 |
| B-roll 模拟输入 | 解释提示词、参数与返回格式 | 明示“模拟示例”，保留必要上下文；输入动画速度服从阅读，不逐字拖慢长段代码 |
| B-roll 软件界面 | 指出配置位置、按钮或状态 | 使用真实截图或清楚标注的示意界面；局部放大实际关注区域 |
| B-roll 屏幕录制 | 证明操作过程与运行结果 | 使用实际录屏，保护敏感信息；生成画面不能冒充成功运行证据 |
| B-roll 动作场景 | 用具体行为解释抽象概念 | 小天拿、递、检查或阻止一个对象；隐喻只说明概念，不替代精确机制图 |

这些是内容表达方式，共用米白、蓝绿、暖橙与温暖手绘品牌基调；真实软件界面保留原貌，可用统一边框与标注整合。章节页与模拟输入可复用版式，避免每镜重新设计。B-roll 不要求人物常驻，更不能为露出人物而遮住代码或压小正文。

静态卡片、真实录屏和适度镜头推拉可以作为 B-roll；整片若承诺“小天动画”，仍须有符合分镜的实际人物动作，不能仅靠卡片切换交差。

## 先稳住人物，再做运动

以共用角色规范为身份来源，先核对关键帧的脸、眼镜、猫耳、服装、左右腕带、手部和比例。身份参考与当前镜头关键帧分别标明用途；不把上一次生成的末帧自动升级为新身份母版，防止逐镜漂移。

头颈肩按 [角色规范](../references/character.md#头颈肩与领口衔接) 构造。参考中的黑 T 恤贴颈效果不能直接搬成卫衣硬领圈：小天下颌下保留短颈，领口贴颈根，帽兜落在颈后，肩膀支撑头部。转头时头与颈根保持连接；大幅看向侧面时允许肩胸小幅跟随。抬臂由肩带动，不能靠拉长脖子、漂移头部或抬高帽兜补偿。

每镜只安排一个主动作，眨眼、呼吸等作为轻微附属运动。先写“起势 → 动作 → 停稳”，再指定镜头运动；通常先固定机位以便发现变形。不要把“人物活泼”写成全身持续晃动。不同景别可以改变人物大小，但不能重新设计头身比例。

## 声音、字幕与合成

- 有旁白时，草稿阶段可估时；取得定稿音频后，按实际片段时长与停顿校准镜头、动作和字幕，再锁定最终时间轴。无须为了遵循固定制作顺序重复生成已有合格素材。
- 区分“旁白配画面”和“角色对口型”。只有要求角色开口说话时安排口型同步；不能用随机嘴部开合宣称完成对口型。
- 字幕依据最终音频对齐，复核技术词、数字、英文标识与断句；不只按稿件字数平均分配时间。字幕位于预留安全区，不能挡住手势、按钮和底部结果。
- 角色与场景可用生成素材；精确文字、代码、流程箭头和字幕优先独立合成，避免视频模型重画而跳字。已有 HTML/SVG 或剪辑渲染能力可承担信息动画与合成，不因此假设它能生成角色关节运动。
- 检查原素材时长、尺寸和声音状态，复用合格素材；需要延长时优先调整停留或补镜头，避免把人物动作强行慢放到失真。背景音乐不得盖过讲解。
- 用户只要预览时交付预览并说明状态；要求最终动画时完成渲染和播放检查。浏览器预览、分镜表与渲染任务提交成功均不等于成片完成。

## 每镜头记录

| 字段 | 要求 |
|---|---|
| 内容与时长 | 要解释的命题、依据、预计秒数 |
| 类型与台词 | A-roll 或具体 B-roll 类型、对应旁白；有音频后记录实际起止时间 |
| 参考与起点 | 真实参考路径、人物方向、手势、道具和镜头景别 |
| 运动 | 起始姿态 → 动作过程 → 结束姿态，写清身体部位和目标 |
| 摄影与背景 | 固定/移动镜头、移动方向、背景是否变化 |
| 信息与声音 | 精确标签、出现时机；旁白、音效、字幕或明确无声 |
| 连续性 | 下一镜头继承的服饰、位置、朝向、道具与动作状态 |

运动提示词从这份记录编写，避免只有“自然、生动、流畅”等形容词。例如：小天先看向镜头，再抬起右手指向画面右侧的知识卡片，目光跟随，最后保持指向姿态；固定镜头，左腕工具腕带和服饰不变。

## 可复用提示词

实际使用时补全方括号，连同已查看的角色参考与当前关键帧输入工具；文字模板不能代替参考图片。时长与动作按镜头调整，不要求每个模板都生成一遍。

**A-roll：提出问题或讲解重点**

```text
小天 Agent，严格沿用提供的角色身份参考与温暖手绘风。16:9，中景，人物位于画面左侧，右侧为后期关键词预留空间。深蓝卫衣、咖啡杯齿轮徽记和自身左腕工具腕带保持一致。短颈自然连接下颌与肩膀，柔软领口贴颈根，帽兜位于颈后。
本镜头解释：[一个核心判断]。起始看向镜头，随后右手抬至胸前做一次解释手势，最后自然停稳；目光与手势协调，头颈肩连接稳定。固定机位，无持续摇摆，不变换服装和脸型。
声音方式：[旁白配画面 / 明确台词并对口型 / 无声]。不在生成画面中绘制字幕和长文字，后期叠加。
```

**B-roll：技术机制分步演示**

```text
制作温暖手绘信息动画，内容为：[经核实的节点、关系、精确标签]。
画面按 [步骤一 → 步骤二 → 步骤三] 依次高亮，每次只突出当前变化，其余节点稳定；箭头代表 [数据 / 调用 / 控制流]，不得混用。
文字、代码与箭头使用可控图层叠加，背景米白，蓝绿区分节点，暖橙仅强调当前步骤。小天 [不出现 / 位于不遮挡内容的一侧，指向当前节点]。按对应旁白留出阅读时间。
```

**B-roll：用动作解释概念**

```text
沿用小天身份与当前场景关键帧。本镜头解释：[概念]，用 [具体道具与行为] 表达。
小天先 [起始姿态]，再 [一个主要动作及作用对象]，最后 [结果姿态与停留]。视线跟随目标，肩、肘、腕自然联动；短颈与领口保持稳定，不拉长脖颈，不让头部漂离肩线。固定镜头，道具只出现一次并保持形状。
只表达指定关系，不自行增加角色、标志或装饰；所需标签后期叠加。
```

## 品牌与验收

沿用温暖手绘风、蓝绿与暖橙配色、固定人物规范；不因视频自动改成 3D 或真人风。没有要求时不添加第二套造型。

- 播放检查实际人物关节、手势或表情是否按脚本变化；不能只有镜头推拉。
- 检查首、中、尾以及动作转折处：脸型、猫耳、眼镜、徽记、腕带、手指与道具是否漂移、闪烁或穿模。
- 特别检查转头、点头、抬臂的极值与回位：颈部是否突然变长，头是否脱离肩线，领口是否变成硬环，帽兜是否吞下巴。先修关键帧结构或降低动作幅度，再重做失败镜头，不能用镜头裁切遮盖缺陷。
- 检查镜头衔接、技术标签、流程方向、字幕与声音时序；口型只在要求说话时检查，不能声称未验证的音画同步。
- 检查素材切换前后是否跳换人物比例、手中道具与左右方向；替换某镜头后复查相邻转场及后续字幕时间，避免局部修复打乱整条时间轴。
- 检查文件可播放、时长和尺寸符合要求。逐帧截图只能辅助，不能代替连续播放检查；无法播放时明确验收限制。

优先修失败镜头，不无故重做全片；同一主要缺陷连续两次修复失败则报告限制，停止无界重试。视频生成失败时保留脚本和关键帧，但明确成片未完成。

输出到当前工作区，不写入技能包。交付实际视频链接、时长/尺寸/声音状态和已知缺陷。生成记录包括实际工具、输入参考、提示词、成功/失败状态；不能编造不存在的文件和验证结果。
