# 小天 Agent 角色规范 v0.2

## 默认身份

小天 Agent 是猫耳拟人程序员，亲切、好学、会观察与核实，也会诚实表达未知。以下规范及包内图片构成可直接使用的默认角色，无需历史对话或额外素材。

| 部位 | 默认规范 |
|---|---|
| 头发 | 深棕色微乱短发，蓬松分束刘海，露出眼睛；轮廓参考包内人物 |
| 耳朵 | 一对深色柔软三角猫耳，耳内浅灰米色；不换成天线、不自行增加尾巴 |
| 眼睛与眼镜 | 自然深棕圆眼、圆形黑框眼镜；无代码瞳孔、无发光镜片 |
| 上装 | 深蓝卫衣，胸前米色简化咖啡杯 + 齿轮徽记，无文字 |
| 下装 | 深灰工装裤，简洁侧袋；深灰低帮运动鞋，无品牌标志 |
| 配件 | 角色自身左侧深灰蓝工具腕带，小型矩形装置；按解剖侧判断，不固定在画面左侧 |
| 比例与气质 | 默认全身约三头身、圆润脸型；年轻成年人的亲切与好奇，Q 版可爱专业 |
| 头颈肩 | 短而自然的脖颈，下颌与领口之间只露少量皮肤；颈根落在双肩之间，肩线自然向外下方展开 |
| 背面 | 纯深蓝卫衣与自然垂落帽兜，不加背部标识 |

全身比例、鞋型和背面等未充分展示部分是本规范的生成默认值，不是从示例图测得的精确参数。用户提供更完整的专用母版时沿用其明确细节。

可变：动作、表情、朝向、手中道具、景别、位置和背景。道具按用途选择，不默认同时堆放背包、工具箱、放大镜和终端窗口。需要精准多视角复现时说明当前参考的覆盖范围。

## 头颈肩与领口衔接

头、脖颈、肩膀和衣服按同一个姿态整体构造，不把大头贴到细长成人脖子上。三头身指全身设计倾向，不按半身裁切画面反推比例；不将猫耳高度算入脸部头高。

- 正面或轻微侧身：短颈支撑下颌，露肤紧凑，不能形成细长竖柱或大块倒三角。也不要把脖子完全抹掉，让下巴直接粘在胸口。
- 转头或歪头：下颌、颈根、肩膀与领口遵循同一透视，颈根位于胸廓上方；头部不能横向漂离身体支撑位置。避免用拉长脖子来腾出动作空间。
- 卫衣领口：柔软、贴合颈根，有轻微厚度；兜帽自然落在颈后和双肩附近。保留下颌、短颈、领口的层次，避免硬质圆环、围脖式堆叠或把帽兜顶到脸颊。
- 肩膀与抬手：肩宽能支撑头部，抬臂时袖子从肩部连接；不能为了露出徽记而压低领口、拉长颈部或把肩膀缩成一点。
- 阴影：下颌与领口间只用轻柔接触阴影，不画粗黑横带或深色断口，使头看起来悬浮。

上述为形体目标，不宣称精确解剖测量。姿态优先自然，不能用固定像素颈长或强制零露肤处理所有角度。

## 两种表达，共用同一身份

- 标准手绘版：深色干净线条、柔和上色，保留五官和服饰识别细节；用于立绘、近景和口播人物。
- 信息图简化版：减少衣褶和腕带细节，保留相同轮廓、比例、眼镜、猫耳与徽记；用于正文图与内容镜头。

品牌基调：温暖手绘，兼容卡通信息图。深蓝人物搭配柔和蓝绿，少量暖橙。Java 蓝 #007396、Spring 绿 #6DB33F 是品牌色目标，不把卫衣强行改成亮蓝，也不承诺生成像素精确匹配色值。

米白纸纹是整图背景，不烘焙到透明人物素材。不能因“视频”自动换成写实或 3D 造型。

## 包内参考

[默认风格与人物示例](../assets/character-style-reference.png)：用于校准温暖手绘线条、配色、可见人物外观及辅助讲解构图。它是完整信息图示例，不是正侧背设定表；只参考人物和画风，不复制文字、箭头、卡片与技术主题。

该示例的头颈领口衔接不作为形体标准。保留身份和画风，头颈肩按本规范修正，不因“保持参考一致”重复结构缺陷；此说明不代表包内图片已经修复。

生成前实际查看图片并作为图像输入传给支持参考图的工具。不要仅把文件名写进提示词。若工具不支持参考图，使用文字规范并说明此次未使用图像条件，不宣称能精确复现示例。

文章辅助人物可从 25%–30% 画高尝试，按信息密度调整；立绘和 A-roll 不受该比例限制。人物不得遮挡信息；拥挤时调整版面，不能压成难以辨认的角标。

用户提供图时，记录其身份、风格、动作或构图用途；外部构图参考中的人物不能替换小天身份。不得引入其他角色名称、猫头标志或额外徽章。

## 可选：建立用户专用母版

仅当用户要求建立母版时，先做一张正面候选，再按需要扩展其他视角。普通姿态、立绘请求直接生成，不以建立母版为前置条件。

用户认可后将候选记为专用身份参考，保存在当前项目并记录路径与认可范围。普通成品和失败图不自动回流到参考库。仅在明确要求维护技能时更新包内图片和规范。
